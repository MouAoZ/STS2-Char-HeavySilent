# 实机 Review 清单

适用范围：初始化骨架；先单人测试。记录游戏版本、BaseLib 版本、模组版本和包配置。
手动验证优先只启用 BaseLib 与 HeavySilent。自动工作流另外启用独立 HeavySilentTestBridge，并允许本机已有 GodotExplorer；不启用其 MCPTest。
自动流程、用例与档位隔离见[游戏自动测试](../../.agents/skills/sts2-heavysilent-dev/references/game-testing.md)。它使用登记的第 3 档并执行 `unlock all`，保护第 1、2 档；以下清单也可供人类独立 Review。

## 安装与加载

1. 执行 `scripts/dev.ps1 package`，然后在游戏关闭时执行 `deploy`。
2. 从 Steam 启动游戏，确认 public-beta 已完成更新。
3. 在模组设置启用 BaseLib、HeavySilent；若游戏要求，重启一次。
4. 日志应出现 `HeavySilent 0.1.0 initialized`。没有重复 BaseLib，也没有本模组的加载错误。
5. 新局角色选择中出现 Heavy Silent，描述明确说明是开发样例；立绘暂时使用静默。

## 战斗与升级

进入普通战斗，打开开发控制台。先用 `help`、`help card` 查询**当前版本**命令。
模型 ID 为 `HEAVYSILENT_STRIKE`、`HEAVYSILENT_DEFEND`、`HEAVYSILENT_QI`；命令接受的 ID 形式由该版本帮助确认。

| 场景 | 预期 |
| --- | --- |
| 无修正时打击／打击+ | 6／9 伤害，原版目标与动画正常 |
| 无修正时防御／防御+ | 5／8 格挡 |
| 气／气+，抽牌堆充足 | 0 费，抽 1／2 张，进入消耗堆 |
| 气，抽牌堆空、弃牌堆非空 | 正常洗牌并抽牌 |
| 气，所有可抽牌堆均空 | 不报错，仍按原版流程结束出牌与消耗 |
| 气，手牌满／不能抽牌 | 遵循原版抽牌限制，不直接强行移动牌 |
| 力量、敏捷、虚弱等修正 | 游戏正常修正打击与防御数值 |
| 切换简体中文／英文 | 卡名、描述、动态数值和消耗关键词正确显示 |

## 保存与继续

通过游戏支持的保存节点退出测试局，再继续；确认角色、卡牌和升级状态恢复。
这不等于承诺任意时刻的战斗状态可保存，遵循当前游戏本身的保存流程。

本阶段没有完整奖励卡池，不以生成所有稀有度奖励或完成一局为验收标准。
若流程需要超出骨架范围才能继续，记录准确停止位置，不用额外设计填满卡池。

## 结果记录

把日期、版本、执行者、每项通过／失败／未执行和日志线索写入[项目状态](status.md)。
游戏控制台 `open logs` 可定位日志，BaseLib 的 `showlog` 可显示日志窗口。
无法操作 GUI 时应保留“未执行”，不能用打包或无界面资源检查替代实机结果。
