## 范围与交付

特殊机制包括鼠标悬停时需要弹出解释的术语（如磨顶、征召），以及供多项内容共同使用的规则或系统。角色独有的费用、资源、充能球等属于这一层；这些是分类示例，不表示本项目新增了相应设计。

每项特殊机制记录：术语名称与玩家可见解释、完整规则、参数、触发顺序、边界、适用范围和验收例子。涉及可见术语时，结算与术语显示分别跟踪；实现还需接入双语文本、相关卡牌／遗物提示，并实际检查悬停解释。当前磨顶和征召的结算与术语显示均未实现。

气是一张状态牌，定义集中在[卡牌设计](cards.md#hs-token-001)。多张牌共同使用的气生成、转化等规则在本页维护，不能把具体卡牌与共用机制重复计数。实现优先复用原版效果，已查证的类型、方法与差异见[原版效果参考](../../.agents/skills/sts2-heavysilent-dev/references/vanilla-effects.md)。

## 磨顶 X：实现约束

决策来源：[协作 local #1](../collaboration/issues/1.md)。

- 磨顶失败跳过整张卡剩余效果；已发生的前段效果与已支付费用不回退。它不是“牌数不足就禁止普通出牌”的门槛。
- 成功的一次磨顶按一次操作触发，磨顶0也算成功并触发；“磨顶次数”与“磨顶牌数”分别计数。
- 置入弃牌堆不触发原版弃牌效果，沿用策划的“预见”类比。实现使用牌堆移动，不能用普通弃牌事件冒充。
- 需要自动打出时插入结算，参考地狱狂徒的等待式触发；不把所有触发统一延后到整批磨顶完成。自动出牌后继续原结算上下文。
- 被磨顶而自动打出的攻击随机选取合法目标，沿用原版自动出牌和游戏 RNG。轮斩重复打出在不能继续磨顶或敌人死亡触发原版停止条件时截断；不另设未经设计的通用重打上限。

实现时需要使用一次操作的结果关联“其中的牌”，不能在后续步骤重新扫描整个弃牌堆冒充本次磨顶结果。

验收例子（待实现验证）：

| 前提／操作 | 预期 |
| --- | --- |
| 叠障先获得格挡，但随后磨顶2时抽牌堆仅1张 | 前段格挡与费用保留；不移动牌，不获得后段格挡 |
| 抽牌堆为空，执行磨顶0 | 成功，计一次磨顶，磨顶牌数为0，后续效果可继续 |
| 磨顶过程中有牌触发自动打出 | 插入原版自动出牌流程并等待完成，之后恢复本次磨顶；不派发普通弃牌事件 |


## 征召 X：实现约束

决策来源：[协作 local #2](../collaboration/issues/2.md)。征召视作抽牌的子类，触发原版抽牌效果，并遵守禁抽和满手限制。每次实际抽取时读取当前顶牌，触发改变牌堆后继续读取当时的牌堆；本次征召不主动洗牌，但其他插入效果可以按其自身规则洗牌。

本机原版 `CardPileCmd.Draw` 在需要时会洗牌，不能仅改文案就作为征召。实现需复用抽牌事件、历史、选择上下文与限制，并对“不主动洗牌”做最小必要适配。

验收例子（待实现验证）：抽牌堆2张、弃牌堆有牌时征召3，手牌空间足够且无其他触发，则只抽2张；禁抽时不抽；手牌满时按原版停止；插入效果主动洗牌不被征召禁用。

### 生成、复制与转化

- 生成、复制、战斗内转化均计作生成事件。沿用原版生成／转化命令；原版转化已经派发生成记录和 Hook，不能重复通知。
- 加入抽牌堆默认随机插入，参考守墓人生成灵魂；明确指定牌顶或牌底的效果遵守自身文本。随机使用游戏上下文。
- 复制参照愤怒，采用原版战斗实例克隆语义，包括已有升级和修正；不是重新创建未升级的同名牌。
- 气+计作气；生成到手牌时溢出部分进入弃牌堆，参考刀刃之舞。
- 未特别说明时，加牌／复制／转化只影响本场战斗；明确奖励获取、删牌、永久修改或先古替换时才作用于永久 Deck。

验收例子：转化一张牌为气只触发一次生成监听；满手生成两张气时两张均进入弃牌堆；气与气+共同参与“气”的计数；战斗结束后临时转化不改永久 Deck。

### 伤害、斩杀与目标

- “造成伤害”参照拳斗，以原版攻击结果 `TotalDamage + OverkillDamage` 汇总，包含格挡吸收与过量伤害。伤害的一半向下取整。
- 斩杀沿用狩猎的原版判定和术语：检查是否允许触发斩杀及攻击结果是否击杀，不自行用“目标 HP 为0”替代。
- 已死亡目标不接受后续治疗。未注明随机敌人的多段攻击对同一敌人结算，其他目标类型按卡牌明文。
- 涤尘的“所有状态牌”采用散射炮的战斗牌堆范围，排除消耗堆，不修改永久 Deck。已经消耗的状态牌不再消耗，也不计入本次攻击次数；范围修正来源见[local #31 补充回答](../collaboration/issues/31.md#timeline)。目标仍按本卡描述，对同一名敌人结算。

验收例子（待实现验证）：手牌、抽牌堆、弃牌堆各有1张状态牌，消耗堆有2张，且没有其他触发改变牌堆时，涤尘消耗前3张，对同一敌人攻击3次；消耗堆原有的2张不参与。

### 奖励、先古获取与保存

- 舍离在卡牌奖励中被选择时触发永久删牌；赠印在奖励出现时赋予同组其他牌固有与保留；兼收仍在选择该牌时获得其余奖励。获得、选择和出现三个阶段不能互换。
- 上述删牌与赋予保留的改牌为永久效果，需作用于最终进入永久 Deck 的实例并保留到保存续玩；普通战斗内赋予保留见下文。
- 欧罗巴斯初始遗物升级沿用原版替换：砥石被玉砥替换。特殊初始牌转化明确为[偏锋 HS-START-002](cards.md#hs-start-002)→[合流 HS-ANCIENT-001](cards.md#hs-ancient-001)，沿用原版的升级、附魔继承和永久 Deck 保存；确认来源见[local #36 补充回答](../collaboration/issues/36.md#timeline)。
- 易脉经达弗的职业专属先古卡流程获得；按原版 DustyTome 给予升级版并加入永久 Deck。既有 BaseLib 扩展用于接入这三种映射，具体 API 见技术参考。

### 计数、费用、保留与回合

- 按卡牌效果分别记录打出气数、生成牌数、磨顶次数、磨顶牌总数等；标注“本回合”的数据仅计当前回合，随原版回合生命周期重置。消耗堆中气的数量是当时牌堆状态，读取时实时计算，不能误作每回合清零的累加器。
- 普通费用采用原版修正后的实时费用，实际支付下限为0；X 值按原版出牌捕获流程，易脉的特殊捕获公式见下文。
- 伏笔在选牌全部完成时记录所选牌的当前总费用，后续费用变化不重算该金额。返费复用侧步的延迟能量状态，在下个己方回合能量重置后发放已记录金额；确认来源见[local #40 补充回答](../collaboration/issues/40.md#timeline)。
- “本回合保留手牌”按汇流，只保留该回合；“获得保留”按响指为当前战斗牌实例添加保留，持续本场战斗。明确为永久改牌的效果遵守上一节，不将普通响指式保留写回永久 Deck。
- 回合末效果沿用原版 Hook 阶段和监听顺序：同一角色的能力状态按获得顺序，随后遗物；选牌暂停、Late 阶段和手牌清理按原版生命周期处理。实现前为相互作用的具体卡组合核对顺序，不创建全局替代排序器。
- 奇偶回合从战斗开始计数，原版首回合为1，属于奇数回合。

验收例子（待实现验证）：伏笔选牌完成时总费用为3，之后这些牌被减费，下回合仍在己方能量重置后返还3点能量。

### 替代支付、修正与原版术语

- 易脉生效后，能量不足且抽牌堆能完成此次差额所需的全部磨顶时才允许替代支付；优先使用能量，差额每1费磨顶2。不能只完成一部分所需磨顶就打出卡牌。
- 在易脉生效的 X 费出牌中，出牌时先固定 `X = 当前能量 + floor(抽牌堆牌数 / 2)`，后续磨顶与触发不回算本次 X。
- 磨顶修正最低为0；X 或整个抽牌堆先在打出时按文本锁定基础磨顶数，再应用修正，最后判断最终数量能否完成。
- 孤注自带每缺1费磨顶4的支付规则；易脉生效时，优先采用易脉的每缺1费磨顶2。两种情形均优先使用能量，且必须能完成全部差额所需的磨顶；没有易脉时仍可使用孤注自带的支付。确认来源见[local #7 补充回答](../collaboration/issues/7.md#timeline)。
- 击晕采用原版吹哨的机制：使目标怪物在下一回合无法行动，沿用原版死亡目标与后续行动处理。止水对所有敌人逐一调用现有机制，不自建同名 Power。
- 完美契合采用原版附魔：该牌被非初始洗牌洗入抽牌堆时置顶，不改变初始洗牌顺序。合流应接入原版提示和附魔行为，不另造含义相近的关键词。

验收例子（待实现验证）：易脉生效且当前2能量、抽牌堆5张时，X 固定为4；无额外磨顶修正时，孤注缺1费且有易脉则磨顶2，没有易脉则磨顶4；整堆基础数3被修正+1后需要4张，按最终数量判断是否成功；基础数0被修正-1后仍为0。

奖励阶段改牌、获得卡牌时移除卡牌、替代费用支付、复制整个抽牌堆、跨回合费用与回合末返回牌顶，均需要额外核对生命周期。
