# 特殊机制设计

更新日期：2026-10-25。玩法规则在本页维护，Skill 只索引此处。关联内容见[卡牌设计](cards.md)和[遗物／事件／药水设计](relics-events-potions.md)；状态定义与统计见[设计到实现跟踪](implementation-tracker.md)。原始表述来自[历史草稿](archive/设计草稿v0.1.md)。

## 范围与交付

特殊机制包括鼠标悬停时需要弹出解释的术语（如磨顶、征召），以及供多项内容共同使用的规则或系统。角色独有的费用、资源、充能球等属于这一层；这些是分类示例，不表示本项目新增了相应设计。

每项特殊机制记录：术语名称与玩家可见解释、完整规则、参数、触发顺序、边界、适用范围和验收例子。涉及可见术语时，结算与术语显示分别跟踪；实现还需接入双语文本、相关卡牌／遗物提示，并实际检查悬停解释。当前磨顶和征召的结算与术语显示均未实现。

气是一张状态牌，定义集中在[卡牌设计](cards.md#hs-token-001)。多张牌共同使用的气生成、转化等规则在本页讨论，不能把具体卡牌与共用机制重复计数。

## 磨顶 X：待确认与实现约束

不能把普通弃牌命令直接认定为磨顶，因为弃牌触发、牌堆来源和失败语义需要单独确认。

| 问题 | 为什么影响实现 |
| --- | --- |
| “后续操作”是本次关联效果，还是整张卡剩余效果？ | 决定多段卡和“伤害—磨顶—治疗”的控制流 |
| 不足时是否仍支付出牌费用？ | 设计的是使用门槛还是结算失败，影响不同接口 |
| 一次磨顶按一次操作还是逐张触发？ | 影响本回合次数和每当磨顶的监听 |
| 磨顶 0 是否成功并触发？ | X 费牌、空抽牌堆和递归效果的边界 |
| 磨顶是否触发原版弃牌效果？ | 牌堆移动与 Discard 并不等价 |
| 先批量移完，再自动打出，还是边移边打？ | 自动出牌可能抽牌、洗牌或改变待移动对象 |
| 被磨顶的攻击自动选择谁？ | 目标与随机数需要由游戏流程处理 |
| 自动重复打出的终止条件是什么？ | 避免无限递归与死亡目标继续结算 |

实现时需要使用一次操作的结果关联“其中的牌”，不能在后续步骤重新扫描整个弃牌堆冒充本次磨顶结果。

## 征召 X：待确认与实现约束

本机原版 `CardPileCmd.Draw` 在需要时会洗牌，因此不能直接调用它并宣称征召成立。

实现前确认：

- 是否触发所有普通“抽到卡牌”效果，以及与不能抽牌的状态怎样交互。
- 手牌满时按原版抽牌限制处理，还是有其他行为。
- 抽牌触发造成牌堆变化时，针对开始时的快照还是逐张读取。
- 是否允许本次征召以外的触发效果自行洗牌。

## 共用交互待澄清

下列问题跨多张卡牌或其他内容共享，集中记录以免各自给出不同答案。它们不是已经定义完成的额外术语，不另增机制计数；在对应内容启动时确认，之后再形成正式规则与验收例子。

| 编号 | 需要明确的边界 | 影响范围 |
| --- | --- | --- |
| <a id="q3"></a>Q3 | 生成／复制／转化是否同类事件；插入抽牌堆的位置与顺序；复制保留哪些修正；气+是否计作气；转化是否计为生成；满手牌的处理。 | 加气、转化、复制、气计数及生成监听 |
| <a id="q4"></a>Q4 | “造成伤害”的数值口径、伤害一半的取整、斩杀判定与治疗死亡目标；“卡组中所有状态牌”指哪些牌堆、多段攻击如何选目标。 | 虚弱层数、伤害生气、斩杀、状态消耗、伤害后治疗 |
| <a id="q5"></a>Q5 | 奖励出现／选择／获得的触发边界；删牌和赋予保留是否永久；先古内容的获取、替换对象与保存范围。 | 奖励干预、获得时删牌、斩杀改牌、先古卡与遗物 |
| <a id="q6"></a>Q6 | 回合内计数的范围与重置；费用读取时点及下限；跨回合返费的费用快照；保留持续期与回合末结算顺序；奇偶回合起点。 | 连击／减费、入弃牌计数、延迟费用、保留与回合触发 |
| <a id="q7"></a>Q7 | 磨顶替代支付的可用条件、部分支付与失败；磨顶修正对X／整堆／零或负数的作用；击晕与“完美契合”的目标版本语义。 | 替代支付技能、磨顶加减能力、击晕技能、先古卡 |

奖励阶段改牌、获得卡牌时移除卡牌、替代费用支付、复制整个抽牌堆、跨回合费用与回合末返回牌顶，均需要额外核对生命周期。Q4 中“卡组”需要区分永久 Deck 与战斗各牌堆；Q3 中临时生成与永久加牌同样需要区分。

卡牌自身未明确的升级与可打出性集中在[卡牌设计 Q8](cards.md#q8)。确认后的规则写回本页，相关卡牌、遗物、事件与药水引用本页，不在 Skill 中另写一套。新增机制可使用[特殊机制模板](templates/mechanic.md)。
