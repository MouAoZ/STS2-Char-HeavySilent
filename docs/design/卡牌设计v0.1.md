# 机制解释

磨顶X：将牌堆顶X张牌置入弃牌堆。若此时牌堆顶牌数小于X，则不执行磨顶及其后续操作。

气：状态牌，0费，抽1（2）张牌，消耗。

征召X：从牌堆顶抽X张牌。若此时牌堆顶牌数小于X，则将牌堆中余下所有牌抽入手中，不洗牌。
