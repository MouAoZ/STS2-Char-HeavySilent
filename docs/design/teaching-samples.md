# 初始化教学样例

这份文档描述当前可运行的教学内容。原始[卡牌设计 v0.1](卡牌设计v0.1.md)保留原样；测试占位不代表修改正式起始套牌。

| 设计编号 | 稳定模型 ID | 设计 | 实现 |
| --- | --- | --- | --- |
| HS-BASE-001 | HEAVYSILENT_STRIKE | 基础攻击，1 费，单体 6（9）伤害，打击标签 | [HeavyStrike](../../HeavySilentCode/Cards/HeavyStrike.cs) |
| HS-BASE-002 | HEAVYSILENT_DEFEND | 基础技能，1 费，获得 5（8）格挡，防御标签 | [HeavyDefend](../../HeavySilentCode/Cards/HeavyDefend.cs) |
| HS-TOKEN-001 | HEAVYSILENT_QI | 状态牌，0 费，无目标，抽 1（2）张牌，消耗 | [Qi](../../HeavySilentCode/Cards/Qi.cs) |

打击／防御采用原版基础数值作为工程样例；气的数值来自原设计稿。升级保持费用与关键词不变，只改变对应动态数值。

## 气的效果顺序

1. 通过普通出牌流程进入结算。
2. 调用原版抽牌命令，按当前版本处理洗牌、手牌上限、不能抽牌等效果。
3. 原版出牌流程根据 `Exhaust` 关键词把气放入消耗堆。

因此气在抽牌过程中尚未结束本次出牌，不应人为提前把自己放入消耗堆；也不能再手动消耗一次。
普通抽牌会洗牌，原设计中“征召不洗牌”的限制不适用于气。

## 测试套牌

[角色定义](../../HeavySilentCode/Character/HeavySilentCharacter.cs)使用五张打击、五张防御和两张气。
两张气是便于验证的临时替代；正式设计中的“加气防御”和“磨顶后按牌堆差值攻击”尚未实现。
现阶段也没有普通／罕见／稀有奖励卡，奖励池完整性和通关不属于初始化验收。

## 验收例子

- 无修正时打击／打击+分别造成 6／9 伤害；力量和敌人格挡仍经原版结算。
- 无修正时防御／防御+获得 5／8 格挡；敏捷仍生效。
- 抽牌堆有足够牌时，气／气+抽 1／2 张，且自己最终进入消耗堆。
- 抽牌堆为空且弃牌堆非空时，气能触发普通洗牌。
- 通过游戏支持的保存节点继续测试局后，卡牌 ID 和升级状态能够恢复。
