# 策划模板

按[设计入口](../README.md)选择类别，将对应模板填入所属设计文档的条目；内容复杂时可另拆详情页并从所属文档链接。模板是供人阅读的约定，不是游戏或脚本读取的配置格式。

- [特殊机制](mechanic.md)：术语悬停解释、共用规则、触发顺序、边界与验收。
- [卡牌](card.md)：中英文名及命名状态、数值、目标、升级、效果顺序。
- [遗物](relic.md)：中英文名及命名状态、触发时机、计数、重置和保存范围。
- [药水](potion.md)：中英文名及命名状态、使用条件、目标、即时效果。
- [事件](event.md)：中英文名及命名状态、出现条件、页面分支、代价和结果。

设计编号与实现状态登记在所属设计文档，[设计到实现跟踪](../implementation-tracker.md)维护编号约定及汇总；已有条目沿用编号，新设计由 Agent 分配下一个未用编号。名称、顺序或稀有度调整不重编号，也不要更换已进入存档的稳定模型 ID。
不确定的规则写“待确认”，问题与回答登记在[协作文档](../../collaboration.md)，模板中的待确认栏只填 local Issue 编号与链接；不用为了填满模板提前设计无关系统。
Agent 应将已实现、可复用、需要新机制和存在歧义的部分分开说明。
