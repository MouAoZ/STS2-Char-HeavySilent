# 策划模板

复制对应文件到 `docs/design/` 下的新文档，填写后交给 Agent。模板是供人阅读的约定，不是游戏或脚本读取的配置格式。

- [卡牌](card.md)：卡名、数值、目标、升级、效果顺序。
- [遗物](relic.md)：触发时机、计数、重置和保存范围。
- [药水](potion.md)：使用条件、目标、即时效果。
- [事件](event.md)：出现条件、页面分支、代价和结果。

设计编号由 Agent 在实现前分配并登记；不要因为重命名卡牌就更换稳定模型 ID。
不确定的规则写“待确认”，不用为了填满模板提前设计无关系统。
Agent 应将已实现、可复用、需要新机制和存在歧义的部分分开说明。
