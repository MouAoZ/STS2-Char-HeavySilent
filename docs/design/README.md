# 设计文档

当前设计按下列三类分别维护。每个条目在所属文档中记录设计编号、效果或规则、实现状态、代码位置及待澄清项；[进度跟踪](implementation-tracker.md)汇总统计，[README 看板](../../README.md#开发看板)安排工作，[项目状态](../development/status.md)保存验证证据。

| 类别 | 文档 | 归属边界 |
| --- | --- | --- |
| 特殊机制设计 | [mechanics.md](mechanics.md) | 鼠标悬停显示解释的术语，以及跨内容共用的规则、资源或系统；当前为磨顶、征召 |
| 卡牌设计 | [cards.md](cards.md) | 初始卡组、角色卡牌、状态牌、诅咒牌、先古卡、其他特殊奖励卡；气放在状态牌 |
| 遗物／事件／药水设计 | [relics-events-potions.md](relics-events-potions.md) | 分别记录三类内容的触发、流程、使用条件与效果；涉及卡牌或共用机制时引用其设计 |

## 如何维护

- 直接修改所属设计文档。共用规则只写在特殊机制文档，卡牌、遗物、事件、药水和项目 Skill 都引用它。
- 事件给予的特殊卡仍属于卡牌设计，事件文档只记录获取入口与设计编号；初始遗物和先古遗物升级属于遗物设计，先古卡属于卡牌设计。
- 新增内容可使用[策划模板](templates/README.md)。不明确的规则先记为待澄清，不在整理文档时补定玩法。
- [教学样例](teaching-samples.md)解释现有代码与验收方式；技术工作流仍在[项目 Skill](../../.agents/skills/sts2-heavysilent-dev/SKILL.md)及其参考中。Skill 不保存独立的玩法规则正文。
