## 命名约定

遗物、事件与药水均单列中文名和英文名，暂名直接填写在名称栏，不另设检索短名。当前四件遗物的中英文名均为 **Agent 拟定的暂名，待策划定稿**；事件与药水尚无具体设计，先预留栏目。

后续定名时替换中英文名即可，设计编号、页内锚点与已进入存档的模型 ID 保持稳定。命名状态与设计／实现状态分别记录，名称不构成玩法规则，也不表示效果已实现。
