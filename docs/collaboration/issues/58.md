# local Issue #58 · 替代支付在插入效果后失败

## Description

local #44–#46 要求替代支付开始时可完成全部差额；local #57 又明确先觉先抽后检查。这两个规则组合后，开始满足资格的支付也可能失败。例如易脉生效、打出2费牌、1能量、抽牌堆2张且有先觉：开始可磨顶2代付1费，但先觉抽走1张后不足。

这种失败如何处理源卡与已支付能量？建议按普通磨顶失败：源卡算作打出，支付现有能量，跳过其全部效果并按原版进入弃牌／消耗等结果位置；保留先觉已经抽到的牌。另一种可选规则是取消打出、源卡留手、退回已经支付的能量，但不回滚先觉抽牌。这里涉及玩家可重复触发抽牌的行为，需要人类选择。

另，易脉X费按已定公式先锁定X；若微调使代付磨顶数量增加并超出现有牌数，建议在出牌资格检查阶段禁止打出，不进入先觉或支付。
