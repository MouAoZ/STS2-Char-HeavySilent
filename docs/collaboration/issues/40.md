## Timeline

### 2026-10-26 · Agent

侧步在打出时记录固定能量数，下回合能量重置后发放；它不选牌，也不读取所选牌费用，所以无法直接证明伏笔应使用哪个费用时点。

伏笔在选牌时锁定这些牌的总费用，还是到下回合返费时再读取？前者可直接记录到原版延迟能量状态，后者需保存选中牌的关联并延迟计算；中途减费会产生不同结果。

### 2026-10-26 · 人类

选完牌时记录所选牌当前总费用, 下回合的返还费用时点参照侧步.

### 2026-10-26 · Agent

已更新[伏笔](../../design/cards.md#hs-skl-020)及[费用与回合规则](../../design/mechanics.md#计数费用保留与回合)：选牌全部完成时记录所选牌的当前总费用，之后费用变化不重算该金额；复用侧步的原版延迟能量状态，于下个己方回合能量重置后发放。local #6 已关闭，伏笔仍未实现。
